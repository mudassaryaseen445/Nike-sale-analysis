# Nike-sale-analysis
Nike sales data cleaning, exploratory data analysis, visualization, and statistical analysis using Python.
# Project Overview
This project focuses on cleaning, preprocessing, and analyzing Nike sales data using Python. The dataset contains 2,500 records with information about products, sales, revenue, profit, regions, sales channels, discounts, and order dates.
# Workflow
- Data Loading & Initial Inspection
- Data Cleaning & Standardization
- Missing Value Handling & Imputation
- Invalid Value Detection & Correction
- Duplicate Identification
- Data Validation
- Exploratory Data Analysis (EDA)
- Data Visualization
- Correlation & Outlier Analysis
- Statistical Hypothesis Testing
- Business-oriented Sales & Profit Analysis
# Technologies Used
- Python
- Pandas – Data manipulation and cleaning
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical visualization
- SciPy – Statistical analysis
- Jupyter Notebook – Development environment
# Purpose
The main purpose of this project is to transform an uncleaned sales dataset into a reliable dataset and perform Exploratory Data Analysis (EDA) to identify patterns and relationships in sales, revenue, profit, products, regions, and sales channels.
